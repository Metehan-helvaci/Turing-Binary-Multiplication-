1 Problem Tanımı
Bu projede Python programlama dili kullanılarak tek bantlı bir Turing Makinesi simülatörü geliştirilmiştir. Sistem kullanıcıdan alınan iki binary sayıyı çarpmaktadır.
Makine aşağıdaki işlemleri gerçekleştirmektedir:
•	Binary giriş alma
•	Operand ayrıştırma
•	Çarpma işlemi
•	Sonucun banda yazılması
